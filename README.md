# 🚗 Car Price Prediction

A Machine Learning web application built using **Python**, **Scikit-learn**, and **Streamlit** that predicts the estimated price of a car based on its specifications. The application provides an interactive user interface where users can enter vehicle details and receive an instant price prediction.



# 📖 Project Overview

Car price prediction is an important regression problem in the automotive industry. The value of a vehicle depends on several factors such as its brand, fuel type, engine specifications, dimensions, and performance characteristics.

This project uses a Machine Learning model trained on automobile data to estimate the selling price of a car. The trained model is deployed using **Streamlit**, enabling users to interact with the model through a simple and user-friendly web application.



# 🎯 Project Objective

The main objectives of this project are:

- Predict the estimated price of a car using Machine Learning.
- Build an interactive web application using Streamlit.
- Demonstrate an end-to-end Machine Learning workflow.
- Help users estimate vehicle prices based on technical specifications.
- Showcase Machine Learning model deployment using GitHub and Streamlit Community Cloud.

# ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/himanshitikhe/Automible_Prediction.git
```

### 2. Navigate to the project directory

```bash
cd Automible_Prediction
```

### 3. Install the required libraries

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit application

```bash
streamlit run app.py
```

The application will open automatically in your browser.
